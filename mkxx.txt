标题
用 # 表示，几个 # 就是几级标题，最多六级：

markdown
# 一级标题
## 二级标题
### 三级标题
强调
markdown
*斜体* 或 _斜体_
**粗体** 或 __粗体__
***粗斜体***
~~删除线~~
列表
无序列表用 -、* 或 +：

markdown
- 第一项
- 第二项
  - 缩进两个空格表示子项
有序列表用数字加 .：

markdown
1. 第一步
2. 第二步
代码
行内代码用反引号包起来：

markdown
运行 `uv init` 初始化项目
代码块用三个反引号，后面可以标注语言，GitHub 上会高亮：

markdown
```bash
sudo apt update
sudo apt install python3-pip
```
链接与图片
markdown
[链接文字](https://example.com)
![图片描述](图片地址.png)
引用
用 > 表示引用：

markdown
> 这是一段引用文字
表格
用 | 分隔列，用 --- 分隔表头：

markdown
| 命令 | 作用 |
| --- | --- |
| `cp` | 复制文件 |
| `tar` | 解压文件 |
分隔线
三个或以上的 -、* 或 _：

markdown
---
任务列表
GitHub 上很实用：

markdown
- [x] 已完成的任务
- [ ] 未完成的任务
换行
在行尾加两个空格再回车，或者空一行，才会真正换行。直接回车在渲染后会被合并成一行。

💡 记笔记的实用建议
标题层级不要跳：从 # 到 ## 再到 ###，不要从 # 直接跳到 ###

代码块标注语言：写 bash、python、csharp 等，高亮效果更好

表格对齐：|:---| 左对齐，|---:| 右对齐，|:---:| 居中

VS Code 预览：按 Ctrl+Shift+V 实时看渲染效果
